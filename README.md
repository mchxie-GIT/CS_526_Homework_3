# CS526 Homework 3

- **Problem 1:** Remove spaces and compare the string with its reverse. Print each result and count the palindromes.
- **Problem 2:** One recursive function extends a substring's ending position. Another moves its starting position. A set removes duplicates, and sorting puts it in alphabetical order.
- **Problem 3:** The array stack uses a Python list. The singly linked stack stores the top node and its next link. The doubly linked stack also maintains previous links. Reversal removes the top value, reverses the rest recursively, then inserts the removed value at the bottom recursively.
- **Problem 4:** For each pair of streams, compare their directions using integer multiplication. All nonparallel infinite lines cross. For parallel lines, check whether one starting point lies on the other line. If yes, the lines are counted as crossing. Otherwise, they don't. All ghosts are eliminated only if every pair passes these checks.
